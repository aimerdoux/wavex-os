## Day 1 Setup Walkthrough (Tony — within 24h of close)

**Hour 0–1**
- [ ] Send Welcome Slack DM (see welcome-email-template.txt in this dir)
- [ ] Create dashboard access: read-only API key or GitHub org invite
- [ ] Record and send 5-min Welcome Loom (script in intake-templates doc on WAVAAAA-450)

**Hour 1–24**
- [ ] Log baseline metrics from intake answers (flaky test count, manual regression hours, deploy confidence 1–5)
- [ ] Schedule Week 1 sync (30 min) or confirm async preference
- [ ] Block Day 3–5 slot for first smoke-test run

**Day 3–5 — First Smoke-Test Run (15 min)**
1. Tony shares screen; partner observes first run (5 min)
2. Partner drives one test with Tony on call (5 min)
3. Q&A + agree what to automate next (5 min)

*Async alternative:* Tony pre-records Loom walkthrough; partner does solo run within 48h and replies async.
